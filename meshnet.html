MeshNet

A browser interface for a Meshtastic network — LoRa radios that route around whatever's missing.

Python · Flask · Meshtastic · MQTT
Routing

No node is load-bearing

Every radio is a relay. A packet floods outward, gets rebroadcast by whoever hears it, and dies at a hop limit rather than at a routing table. Kill any node above and the traffic simply takes a longer road.

Hop count is the whole cost model. There's no bandwidth to speak of — a few hundred bits per second — so the interface is built around text, position and telemetry, not anything resembling a feed.

The bug

Nodes that existed but would not appear

Nodes were live on the mesh and visible on the handhelds, but the web interface showed nothing at all. Two separate faults in the MQTT path, stacked, both of which looked exactly like "the mesh is down."

Symptom

Zero nodes in the interface while packets were visibly arriving and the handhelds showed a healthy neighbour count.

Cause one

Never subscribed to msh/US/2/json/e/#. The topic carrying node info simply wasn't in the subscription list.

Cause two

An envelope-format decoding gap — packets that did arrive were unwrapped incorrectly and dropped before they reached the node table.

Lesson

When the radios and the dashboard disagree, the radios are right. Debug the bridge, not the mesh.

Why it exists

The layer beneath everything else

It shares a purpose with PyVarAC — communications that don't assume infrastructure — but at a different range and a different price.

HF · VARA

Hundreds to thousands of miles. Needs a licence, a rig, an antenna, and a PC running a closed modem binary.

LoRa · Meshtastic

A few miles per hop, further with elevation. No licence, $30 a node, runs on a coin cell for days.

Same UI shape

Both landed on a browser front end over a local server, so the same tablet drives either backend. The launcher handles a uv-managed Python install and forced --break-system-packages.

Same rule

Nothing in the path may require the internet to be up. MQTT is a convenience, never a dependency.

Meshtastic · 915 MHz · hop-limited flood

The mesh above runs the real routing rule: flood outward, rebroadcast once, stop at the hop limit. Kill nodes and watch the path lengthen until there isn't one.
