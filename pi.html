01Why it exists

What leaves the phone

The phone build runs in Termux on Android. Chat text goes to a large model because a 70B model won't fit in a pocket; everything else stays put. Camera frames and vision run locally on moondream, and GPS, the clipboard, contacts, the call log and every device action never leave the device.

The browser version below keeps the character with what a browser can do: a handful of real device tools, AutoFaber's free models for the thinking, and the same orb.

02Parts list

  1. It degrades, it doesn't go quietThree voices tried in order: a neural voice, the device's own voices, then text. Drop the signal and Nobody keeps talking.
  2. It can touch the phone22 tools on the phone build through Termux:API; in the browser, time, battery, location, clipboard, vibration, the camera, timers, links and sharing.
  3. A gate that can't be misreadAnything that reaches outside waits behind a confirmation keyed to a token, so a stray “no” in the next sentence can't deny something already approved.
  4. Nobody is homeEvery version of assistant-voice was cut, one session at a time: answer, be brief, don't apologise, don't offer more help. The inverse of Weaver.

04Construction

The phone build

Termux from F-Droid (the Play Store build silently lacks camera capture), Termux:API, proot Ubuntu, Flask on :8420 with streaming, Groq for chat with Ollama as the fallback, moondream for local vision, and the orb's glow wired to real speech amplitude.

TermuxFlaskGroqOllamaWebGL

The browser build

Speech recognition on the device where it exists (Whisper through AutoFaber otherwise), AutoFaber's free models with Nobody's terse instructions, and AutoFaber's neural voice with the browser's voices as the fallback.

Web SpeechAutoFaberWeb Audio

05Tolerances

The browser version can't read contacts or run shell actions, and its voice and chat run on AutoFaber's daily free allowance. The phone build is the full thing.
