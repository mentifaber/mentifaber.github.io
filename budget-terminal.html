How This Works

Dashboard — live overview: balance, income, upcoming bills, surplus/deficit.

Income — weekly job pay log + side income (music/software) log, rolling up to monthly/yearly gross and net.

Bills — the source of truth for every bill. Add or edit bills only here.

Calendar — visual month view. Pulls bill names and amounts automatically from the Bills tab by due day.

Transactions — set a starting balance once, then log transactions (or paste a bank CSV) — running balance and current balance calculate automatically and feed the Dashboard.

Daily Spend — turns your weekly surplus into a real "safe to spend today" number, with a savings buffer and a suggested split you fully control.

Analysis — spending by category and this month's income vs. spend, from the Transactions log.

Data & privacy: everything you enter is saved only in this browser's local storage — nothing is sent to a server, and nobody but you can see it. That means it survives refresh and closing the tab, but it's tied to this browser on this device; it won't follow you to a different browser or computer, and clearing site data will erase it. Use "Reset All Data" below for a clean slate, or "Export Backup" to save a copy you can re-import later.

Connecting a Real Bank Feed

A page like this one cannot connect directly to your bank, and no version of this tool ever safely could — that's not a limitation of this build specifically, it's how bank-data providers like Plaid work.

Why not: Plaid Link (the bank-connection widget most apps use) requires a backend server holding a secret API key. That key can never be shipped inside a webpage's code — anyone could open dev tools and steal it, then pull data from every account it touches.

Realistic paths:

Fastest: use an existing consumer app that already does this (Copilot, Monarch Money, YNAB, Rocket Money).

Build it yourself: a real backend project — a server, a database, Plaid integration, and auth so only you can reach your data.

Middle ground, no code: keep using the CSV import already built into the Transactions tab.
