the idea

Find the first domino

A detective game for someone who has actually been on call. Root Cause hands you a broken system, a ticking clock and logs that mix normal traffic, symptoms and red herrings. Diagnose it the way you would for real, then write the postmortem: which component, what cause, and the first log line where it started.

how it plays

Inside Root Cause

01

A system map

Ten components; tapping one runs real diagnostics (dig, curl, df, openssl, pg_stat_activity, wrangler tail, git log), each costing three minutes.

02

Evidence, not guesses

Tap log lines to pin them; the postmortem asks for the component, the cause and the first bad line.

03

Ten incidents

Quick tunnel, disk full, bad deploy, expired cert, deleted DNS, runaway cron, missing index, mail loop, memory leak, purge storm. Then an endless rotation.

04

The duck

A rubber duck asks Socratic questions for a five-minute penalty.

built on
