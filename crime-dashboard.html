Crime Intelligence

Forty-three cities, four crime categories, FBI 2025 data — in one HTML file you can email to somebody.

Leaflet.js · single file · no build · no server
Ranked

Rates, not raw counts

Counting incidents ranks cities by population and tells you nothing. Everything here is per 100,000 residents, with the year-over-year change beside it so a bad year reads differently from a bad decade.

Tap a column header to re-sort. The map above follows whatever category is selected.

Constraints

One file, handed to a friend

The brief was a dashboard someone non-technical could actually open. That ruled out a build step, a package manager, a backend, and any hosting decision at all.

Delivery

A single .html. Double-click it. Works from a USB stick, an email attachment, or a folder on a desktop.

Mapping

Leaflet from a CDN with tiles fetched live — the one thing that needs a connection, and it degrades to the ranked tables without it.

Data

FBI reporting, baked into the file as a JSON literal. No fetch, no CORS, no API key to expire.

Interaction

A sortable, filterable sidebar with colour-coded safety markers on the map. All state in memory — nothing to persist, nothing to configure.

Caveats it states out loud

The data has seams

Voluntary reporting

Agencies opt in. A city that looks safe may simply have reported less completely that year.

Definition drift

Category boundaries shift between reporting standards, so long time series aren't clean comparisons.

City limits ≠ metro

Municipal boundaries carve metro areas arbitrarily. Two cities of the same name-recognition can cover wildly different footprints.

Small denominators

In smaller cities a handful of incidents swings the per-capita rate hard. Rank order at the bottom is noise, not signal.

A dashboard that hides these makes people confident about things they shouldn't be. This one puts them in the interface, not in a footnote nobody scrolls to.
