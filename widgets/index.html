Install

  1. Install KWGT from the Play Store.
  2. Download a widget above. Open the file and choose KWGT — or move it into the Kustom/widgets folder.
  3. Long-press the home screen → Widgets → add a KWGT widget at the size shown on the card.
  4. Tap the empty widget and pick the preset from the Exported tab. Allow location if asked, then tap save.
  5. Optional: select Root → Touch → + → Open link and enter https://mentifaber.com/vigil.html (or /wx/ for weather) so a tap opens the full view.
  6. In KWGT settings set the update interval to 15–30 minutes, and set KWGT's battery use to Unrestricted so it keeps refreshing.

If a card is cut off or leaves a gap, resize the widget one cell, or open the editor and adjust the Card's width. Launch data is rate-limited by its provider, so that widget refreshes at most a few times an hour.
