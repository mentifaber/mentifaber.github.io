01Why it exists

Comms that survive the infrastructure going away

Built for a friend who needs communications that keep working when the grid and the internet don't. HF radio reaches hundreds to thousands of miles off the ionosphere, and the VARA modem turns it into a data link. Skipline (formerly NovarAC, and before that PyVarAC) wraps all of it in one browser screen any ham can run from a tablet, with no Windows desktop to babysit and no assumption that the internet still exists.

02Parts list

  1. Rig controlA parsed Hamlib database of 283 radios from 62 manufacturers, driven through rigctld: frequency, mode, band presets and push-to-talk over CAT, DTR, RTS or VOX.
  2. Chat over VARAA WebSocket bridge to the VARA HF modem over TCP: link to a callsign and talk, with signal-to-noise and speed level on every link.
  3. Offline means offlineThe first build quietly pulled Google Fonts. It was stripped, five fonts are now served by the box, and the rendered page was checked for any outbound request.
  4. Demo modeWith no modem attached, the server simulates one, and so does the console below: tune, key up and hold a pretend QSO.

04Construction

The stack

Transport: a tablet browser over a local WiFi hotspot to the mini-PC, with no router upstream and no DNS. Radio link: the VARA modem on the PC, with a Digirig or SignaLink to the rig; the audio never touches a network. Fallback: ardopcf is the documented open-source path and runs on a Pi if VARA's closed binary ever becomes a problem.

Six files

launch.py starts it (with an optional tunnel when you do want it reachable). server.py bridges the browser to the modem. rig_control.py wraps rigctld, polls every two seconds and marks the rig lost after five straight failures. rig_list.json, index.html and the fonts are the rest. No build step.

05Tolerances

HF needs a licence, a rig, an antenna and a PC running VARA. The console on this page is a demo: the modem and the far station are simulated. The real one is served by the box itself, so it works with no internet at all.
